# 無料構成の成立性を調べるローカル試作

2026-10-21。**本番用メッセンジャーではありません。機密データを投入しません。**
VPS・独自ドメインの契約は保留し、無料を優先するという利用者の最新方針に基づく検証です。
既存SHiCIのフロントエンド、GAS、Matrixの鍵・DB・アカウントは変更していません。

**最新の優先順位：各ユーザー1端末の送受信を先行し、複数端末・復旧キーによる履歴復元は後続段階へ回します。**
単一端末のE2EEの追加試験結果と実装範囲は [MVP.md](MVP.md) を参照してください。

## 現時点の判定

リアルタイム通信と暗号化済み添付の保存は、Cloudflareの無料枠で構成できる見込みがあります。
ただし、**要求されている全機能を無料の本番環境で満たせると実証した段階ではありません。**
Matrix版の端末認証・鍵配布・クロス署名・鍵バックアップ・リカバリーキーの復元を、
この中継APIへそのまま接続することはできません。現時点ではMatrixの代替になりません。
独自の暗号方式や、サーバーへ復号鍵を預ける近道は採用していません。

| 要件 | この試作で確認できたこと | 残っていること |
| --- | --- | --- |
| リアルタイム通信 | WorkersとSQLite-backed Durable ObjectのWebSocketで通知受信 | 実Cloudflare・スマートフォンの速度、切断復帰 |
| 専用の履歴保存 | 相手ペア別の暗号文領域、再送IDの重複保存防止 | 本番ページング、保持期間、バックアップ |
| 添付 | 公式Rustライブラリで暗号化したデータをR2エミュレーターへ保存・取得・復号 | 実R2、スマホの画像・動画・録音、ストリーム化 |
| 非許可者の排除 | 署名済み短期チケット、相手ペア、Origin、期限の検証 | GASの役員確認と結び付ける発行・取消・端末管理 |
| E2EEメッセージ | 公式Rust暗号実装による照合済み単一端末の双方向送受信・改ざん拒否を試験で実証 | 模擬の公開鍵ディレクトリを本番登録APIに置換し、ブラウザUIへ接続する |
| 複数端末・履歴復旧 | Matrix版の既存実装・API依存を調査 | 無料中継版での鍵バックアップ・復旧の実証は未実施 |
| SHiCIの隠し画面 | 既存実装を保持 | 新APIとの接続後、iPhone/Androidで再検証 |
| 月額0円 | 公開や契約をせずローカルで試験 | Cloudflareの実アカウントの契約区分・共有無料枠・R2請求設定を確認 |

暗号文形式の検査は、内容が安全に暗号化されていることの証明ではありません。
今回の添付暗号化テストでは復号鍵はテストプロセスが保持し、R2へは渡していません。
このテストは、端末間の安全な鍵交換や、新端末への履歴復元が完成したことを意味しません。

## 実装と試験

`worker.mjs` は現在のフロントエンドから参照されない独立した試作です。
Cloudflare公式のMiniflare/workerdローカル実行環境を使用します。公開用の設定・deployスクリプトは用意していません。
有効化フラグと32文字以上の署名シークレットがなければ503を返します。
本番のユーザーID・トークン・鍵は試験に使いません。

```sh
npm ci --ignore-scripts
npm test
```

6件の試験が成功しています。

1. 無効状態、偽造・期限切れチケット、非許可Origin、非許可者を含むペアを拒否。
2. WebSocket通知、保存、同じ送信IDの再送、内容差替え拒否、別ペアからの閲覧拒否。
3. Matrixの公式Rust暗号ライブラリ18.9.0による添付暗号化→ローカルR2→復号。別ペアの取得は404。
4. 上限超過サイズの拒否と、同時101件の添付要求が1日100回の保存上限を超えてR2へ到達しないこと。
5. 有効期限切れのチケットで履歴が取得できず、接続済みWebSocketにも新規イベントが配信されないこと。
6. 単一端末同士で公開鍵を照合し、公式Olm/Megolmによる双方向文字送受信、未確認端末への鍵配布拒否、改ざん拒否。

無通信のWebSocketがアラームだけで指定時刻に物理的に閉じる試験は、ローカル環境では期限内の完了を確認できませんでした。
期限切れ後の配信は送信直前にも検査して止めますが、アラーム配信の遅延・無通信接続の解放は実Cloudflareで追加確認が必要です。

Windowsのworkerdでは長い一時パスでR2のファイル作成に失敗したため、
試験用R2領域のみ作業ルートの `work/r2-probe-*` に置いています。製品データではありません。

## 無料枠と費用上の条件

公式情報を2026-10-21に確認しています。料金や提供条件は変わり得ます。

- [Workers Free](https://developers.cloudflare.com/workers/platform/limits/)：1日100,000リクエスト、CPU時間10ms等。
- [Durable Objects Free](https://developers.cloudflare.com/durable-objects/platform/pricing/)：SQLite-backedを使用。計算・読み書き・保存容量それぞれに上限。超過時は操作失敗。
- [R2 Standardの無料枠](https://developers.cloudflare.com/r2/pricing/)：保存10GB-month/月、Class A操作100万回/月、Class B操作1,000万回/月。枠を超える分は有料。
- [R2開始条件](https://developers.cloudflare.com/r2/get-started/)：R2サブスクリプションの追加手続きが必要。実アカウントではまだ実施していない。

試作側の独自上限は、ファイル5MiB、イベント32KiB、累積イベント1,000件、
保守的に数えた保存予算128MiB、1日10,000 API操作、R2保存100回/日、取得1,000回/日、接続15本です。
検証用に小さく設けた値で、本番上限として利用者が決定したものではありません。
上限に達したら新規操作を止め、勝手に課金プランへ切替・古い履歴の削除は行いません。
R2への保存失敗時も予約した予算を残し、障害時に上限を過小計上しない方針です。

これらはCloudflareアカウント全体の「請求上限0円」設定ではありません。
別アプリの消費、バケットへの別経路、リトライ、設定変更、保存済みデータの累積まで含む絶対0円は保証できません。
R2の無料枠は「毎月10GBを新たに無期限保存できる」という意味ではありません。
例えば添付が毎日40MB増えると約1.2GB/月ずつ累積し、削除・退避せず使い続ければ無料の保存枠を超えます。
保持期間や退避は、利用者の了承なく設定しません。

## 暗号化・復旧の実装方針を確定する前の確認

既存 `messaging/client/src/matrix-worker.js` では、端末公開鍵・鍵要求、クロス署名、
秘密ストレージ、鍵バックアップのAPIをMatrix SDKへ依存しています。
[公式Rustライブラリ](https://github.com/matrix-org/matrix-sdk-crypto-wasm)はMatrix向けの状態機械であり、
WebSocketへ送信先を変えるだけの汎用チャットSDKではありません。
追加試験では保守されているプロトコル実装を使い、単一端末同士の暗号化送受信を実証しました。
初期版では本番の端末登録・相手鍵の照合・端末内保存を実装し、SHiCIの認可経路から通しで検証する必要があります。
複数端末・復旧キーは最新の利用者指示に従って後続段階へ回します。初期版の検証が済むまではGAS・Pagesを切り替えません。

再設計以外に、既存Matrixを無料VMで動かす候補も調べました。
[Oracle Always Free](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)では無料の計算資源がありますが、
空き不足や低稼働VM回収の条件があり、安定した業務運用を保証できません。契約・利用はしていません。
今回の試作が通ったことを理由に、有料VPSや独自ドメインを買う必要はありません。

## 公開前の必須判定

1. 利用者のCloudflareアカウントでFreeプランと残枠、R2の請求条件を確認。
2. GAS認可、単一端末の登録・失効、相手鍵照合を含めたE2EEを通しで検証。複数端末・本人の鍵復旧は後続段階。
3. 暗号化バックアップ、累積容量、実際のリクエスト数・CPU時間と不正アクセス対策を検証。
4. 実際のiPhone/Androidで伏せる・バックグラウンド・添付選択・再開時の非表示を検証。

現時点では「無料の通信・添付保存の試作は成功、全要件の無料本番化は未確定」という判断です。
