# 無料構成：SHiCIの隠しメッセージ初期版

## 2026-10-22：暗号化経路のWeb Push接続

現行のCloudflare暗号化メッセージ保存後に、受信者の登録先へWeb Pushを送ります。GASの旧平文メッセージ・旧Push APIは再開しません。
VAPID鍵はWorker Secret `FREE_PUSH_VAPID` にのみ保存し、ブラウザには公開鍵だけを返します。既存のメッセージ暗号鍵とは別です。
登録・停止・設定取得には、役員確認後の短期許可証と登録端末署名の両方が必要です。通常画面では許可を求めません。

- 通知は「SHiCI」「確認事項があります。」の固定表示。本文・送信者・ファイル名・認証情報は通知データへ渡しません。
- 新しいメッセージの保存だけが通知の対象です。鍵配布・添付のアップロード途中・同じ送信IDの再試行では通知しません。
- 配信失敗はメッセージ保存を取り消しません。404/410になった登録先は除去します。自動再送は行いません。
- 通知タップは通常の入口へ戻します。本文をバックグラウンドで復号したり、隠し画面を自動で開いたりしません。
- Apple/Google/MozillaのPushサービスだけを許可し、リダイレクト先へ認証情報を転送しません。
- 配信はbest effortです。通知の有効期限は1時間。同じ未配信通知は集約される場合があります。

確認済み：RFC8291通知データの独立復号、VAPID署名検証、実Rust暗号＋Miniflareでの相手だけへの通知・重複抑止・停止・失効・500エラー時の送信成功、WebKitでの有効化／停止操作。
実機の通知許可と、画面を閉じた状態での受信は公開後に利用者が確認します。GASの再デプロイは不要です。

## 今回つないだ機能

- 既存のGAS役員確認を通過した後、SHiCI内の同じ画面で開く。通常画面に入口や通知を追加しない。
- 初回だけ端末登録の同意と、対面・電話などによる相手との確認コード全体の照合を行う。
- 文字の送信直後の表示、WebSocketによる受信通知、画像・動画・音声・ファイルの暗号化送受信。
- 画像・動画はトーク内に自動プレビュー。表示位置に近い添付から端末内で復号し、動画は再生操作後に再生。音声・その他のファイルは従来どおり「添付を開く」。
- 画面終了・相手の切替時にはメディアの再生と表示を破棄。非対応形式は保存リンクへ切替。ダウンロード失敗は再試行ボタンを表示する。
- 公式Matrix Rust暗号ライブラリ18.9.0のOlm / Megolm / Attachmentを使用。暗号アルゴリズムは自作しない。
- 登録公開鍵は上書き禁止。未確認の端末へ鍵を配布しない。照合済み鍵と署名が一致しない場合は復号・送信を停止。
- メッセージを専用Durable Object、添付を非公開R2へ暗号文で保存。ファイル名・MIME・添付の復号情報もメッセージ内で暗号化。
- 非表示・バックグラウンド・pagehide・伏せ検知で通常画面へ戻り、Worker・本文・添付表示を破棄。再開時は隠し入口の確認からやり直す。

`worker.mjs` は専用の通信APIです。Matrix homeserverやElement Xへ接続するAPIではありません。
暗号ライブラリは公式ですが、認証・公開鍵配布・中継・UIの接続部分は今回の独自実装です。第三者監査済みではありません。
通信先、利用者の組み合わせ、時刻、通信量などのメタデータはサーバーが扱います。

## 初期版の制限

- 添付1件5MiBまで。大きな動画は現時点では送れません。ブラウザで表示可能な形式は端末にも依存します。
- 全体で累計1000メッセージ、保守的な利用量予約128MiBまで。日次API予算10000、R2保存100、取得1000。内部操作もAPI予算に含みます。
- 上限に達したら新しい処理を停止します。自動削除・自動課金への切替は行いません。現状は少人数の本番試験向けの上限です。
- 通知は端末ごとの明示的な許可が必要です。隠し画面の「端末」→「通知を有効にする」で登録し、同じ場所から停止できます。通知には本文・送信者名を含めません。
- ブラウザデータ削除、プライベートブラウズ終了、端末紛失で鍵を失うと履歴を復号できません。別ブラウザでの登録を拒否し、既存鍵を上書きしません。
- 同じスマートフォンでもSafariとChrome、ホーム画面のWebアプリなどは保存領域が異なる場合があります。実機試験後に使う方法を固定してください。
- 端末の鍵は暗号化してIndexedDBに保存します。保存用ラッパー鍵は非抽出のCryptoKeyですが、同一オリジンの悪意あるスクリプトや端末侵害を防ぐものではありません。
- 伏せ検知には対応機種・権限が必要です。OSのアプリ切替サムネイルが必ず隠れることはWebだけでは保証できません。

Chromiumで実際の隠しUIから、2人の初回登録、確認コード一致、リアルタイム送受信、添付取得、閉じて再表示、再読込後の履歴、背景移行時の通常画面復帰を確認。

GASの許可証発行はVMで署名・役員の相手制限を試験しています。ブラウザ結合試験はローカル専用の試験用発行器を使い、実GASの認証を置き換えています。

## ローカルで再確認する手順（開発者向け）

Node.js 22以上。`messaging/client` で `npm ci` と `npm run build`、`messaging/free` で `npm ci` と `npm run dev`。
`http://localhost:4173/test.html` を開きます。この入口とalice/bobはローカル試験専用です。本番には配置しません。
APIは127.0.0.1:8787。試験状態はSHiCIの外側の `kon/work/free-local` に保存します。
登録済みユーザーを別のブラウザ保存領域から開くと拒否されます。業務用アカウント・業務データで試さないでください。

## 本番接続の準備

1. SHiCIを管理しているCloudflareアカウントを確認。Workers Free、SQLite DOの利用可否、R2 Standardの有効化条件、他用途との共有利用量を確認。
2. 本番用の専用非公開R2バケットとWorkerを用意。R2の公開URL・カスタムドメイン・ライフサイクル削除を有効にしない。
3. `wrangler.example.jsonc` を別ファイルへコピーし、バケット名と利用者エイリアスを設定。最初は `ENABLE_FREE_MESSENGER=false` のまま配置。
4. 32文字以上のランダムな共通認証秘密をWorkerの `FREE_AUTH_SECRET` とGASの `EXECUTIVE_FREE_AUTH_SECRET` に設定。これはAPIの認証用で、復号キーではありません。チャット、ソース、配布ZIP、フロントへ入れない。
5. GASのスクリプトプロパティへ以下を設定。

| 名前 | 内容 |
| --- | --- |
| EXECUTIVE_MESSENGER_PROVIDER | cloudflare |
| EXECUTIVE_FREE_API_URL | WorkerのHTTPSルートURL。パス・クエリなし |
| EXECUTIVE_FREE_AUTH_SECRET | 上記の秘密と同じ値 |
| EXECUTIVE_FREE_USERS_JSON | SHiCI実ユーザーIDから一意なエイリアスへのJSON対応表。2〜5人 |

例は `{"実ユーザーID1":"member_one","実ユーザーID2":"member_two"}`。Workerの `FREE_USERS_JSON` は `["member_one","member_two"]`。
GASは既存の役員確認と会話相手の権限を通過した人にのみ、15分の署名付き許可証を発行します。公開設定から許可証を取得する機能はありません。

6. 変更したGAS、`frontend`を段階的に反映し、Workerを有効化。既存設定とPagesのデプロイを戻せるように保存してから行う。
7. 実機2台で登録・照合・送受信・背景移行・再開を試す。初期版の制限を確認した人だけが使う。

この手順による公開・R2の有効化はまだ行っていません。R2は無料枠超過分の課金があるサービスです。上記の小さな上限はアプリ内の抑制で、Cloudflareアカウント全体の費用ゼロを保証しません。
[DO公式料金](https://developers.cloudflare.com/durable-objects/platform/pricing/)と[R2公式料金](https://developers.cloudflare.com/r2/pricing/)を2026-10-21に確認。R2 Standardには無料枠がありますが、アカウントの既存利用と契約画面の確認が必要です。

停止はWorkerの `ENABLE_FREE_MESSENGER=false`。既存接続も最長15分で期限切れになります。即時停止が必要な場合はWorkerルート・デプロイ側で遮断します。
鍵を失ったユーザーのプロフィールやDBを削除して再登録する手順は、履歴復号を失うため本版には設けていません。
